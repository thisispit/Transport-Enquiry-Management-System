# Contributing

## How to contribute
1. Fork the repository.
2. Create a feature branch from `main`.
3. Keep changes focused and small.
4. Follow the existing package structure and naming conventions.
5. Add or update tests when changing behavior.
6. Open a pull request with a clear summary of the change.

## Code style
- Use meaningful names.
- Prefer constructor injection.
- Keep controllers thin and services focused.
- Reuse DTOs and helper methods where possible.

## Scope reminder
- Keep the project simple and interview-friendly.
- Avoid adding JWT, Spring Security, Redis, Kafka, Docker, or other unnecessary infrastructure.
