🗺️ Routes API

/routes
GET /routes?page=0&size=10 Get all routes (paginated)

Returns a paginated list of all transport routes.

Example Response
{
  "content": [
    {
      "id": 101,
      "routeName": "City Connector",
      "source": "Pune",
      "destination": "Mumbai",
      "fare": 250,
      "travelDurationMinutes": 180,
      "availableSeats": 24,
      "active": true,
      "stops": [
        { "stopName": "Hinjewadi", "stopOrder": 1 },
        { "stopName": "Swargate", "stopOrder": 2 }
      ]
    }
  ],
  "totalElements": 1,
  "totalPages": 1
}
GET /routes/search?source=Pune&destination=Mumbai Search routes by source & destination

Filter routes by matching source and/or destination city.

GET /routes/{id} Get a specific route by ID

Returns full route details including all stops.

POST /routes Create a new route

Creates a new transport route. Requires admin access.

Request Body
{
  "routeName": "Express Line",
  "source": "Delhi",
  "destination": "Agra",
  "fare": 350,
  "travelDurationMinutes": 240,
  "availableSeats": 30,
  "active": true,
  "stops": [
    { "stopName": "Noida", "stopOrder": 1 },
    { "stopName": "Mathura", "stopOrder": 2 }
  ]
}

📋 Bookings API

/bookings
GET /bookings Get all bookings

Returns all booking records in the system.

POST /bookings Create a booking

Books seats on a specific route for a user.

Request Body
{
  "userId": 1,
  "routeId": 101,
  "travelDate": "2026-09-15",
  "seatCount": 2
}
DELETE /bookings/{id} Cancel a booking

Cancels an existing booking by its ID.

💬 Feedback API

/feedbacks
GET /feedbacks Get all feedback

Returns all user feedback entries.

POST /feedbacks Submit feedback

Submits a new rating and comment.

Request Body
{
  "userId": 1,
  "routeId": 101,
  "rating": 5,
  "comments": "Excellent service, very punctual!"
}

👤 Users API

/users
POST /users/register Register a new user

Creates a new user account.

Request Body
{
  "fullName": "John Doe",
  "email": "john@example.com",
  "phoneNumber": "9876543210",
  "password": "securePass123"
}
POST /users/login Login / authenticate

Authenticates a user by email and password.

Request Body
{
  "email": "student@example.com",
  "password": "password123"
}
GET /users/{userId} Get user details

Returns user profile information.

POST /users/{userId}/favourites/{routeId} Add route to favourites

Adds a route to the user's saved favourites list.

GET /users/{userId}/favourites Get favourite routes

Lists all routes saved as favourites by this user.

🔒 Admin API

/admin
GET /admin/dashboard Dashboard statistics

Returns total users, routes, bookings, feedbacks, and booking status counts.

GET /admin/bookings?page=0&size=10 All bookings (paginated)

Admin-level paginated view of all bookings in the system.

📍 Stops API

/routes/{routeId}/stops
GET /routes/{routeId}/stops Get all stops for a route

Returns all intermediate stops on a specific route.

POST /routes/{routeId}/stops Add a stop to a route

Adds a new intermediate stop to the route.

Request Body
{
  "stopName": "Lonavala",
  "stopOrder": 3,
  "arrivalTime": "10:30",
  "departureTime": "10:35"
}
PUT /routes/{routeId}/stops/{stopId} Update a stop

Updates the name, order, or timing of an existing stop.

DELETE /routes/{routeId}/stops/{stopId} Delete a stop

Removes a stop from the route.
