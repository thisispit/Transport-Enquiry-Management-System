# ATS-Friendly Resume Content

## Project: Transport Enquiry Management System (TEMS)
## Tech Stack: Java 21, Spring Boot 3, Spring Data JPA, SQLite, Maven, Swagger OpenAPI, JUnit 5, Lombok

- Developed a Java 21 and Spring Boot 3 based Transport Enquiry Management System to support route search, seat booking, booking cancellation, and transport feedback management.
- Designed a clean layered architecture with entities, DTOs, repositories, services, and REST controllers for maintainable and interview-friendly backend development.
- Implemented SQLite persistence with Spring Data JPA relationships for users, routes, stops, bookings, feedback, and favourite routes.
- Integrated validation, pagination, sorting, custom exceptions, and Swagger API documentation to improve usability and code quality.
- Wrote focused JUnit 5 tests for route service, booking service, and route controller to demonstrate testable backend design.
